# DSH Side Chat Plus

一个将 **dsh-sidenote 的可持续侧边研究** 与 **纯文本 Side Chat 的无工具讨论** 合并的独立 DSH 插件。

## 两种模式，一个侧栏

| 能力 | 轻聊 | Agent |
|---|---|---|
| 用途 | 解释选文、讨论方案 | 阅读代码、检索文件、研究实现 |
| 工具 | **不提供任何工具** | 默认仅 `read` / `glob` / `grep` |
| 工作区权限 | 无工具访问 | 默认只读；明确确认后可开放 `write` / `edit` |
| 主会话上下文 | 可选，默认关闭 | 默认带入文字快照，可关闭 |
| 多轮、保存、恢复 | 支持 | 支持文字历史恢复 |
| 独立模型 | 创建时选择 | 创建时选择 |
| 结论回流 | 编辑后追加到主会话草稿 | 同左，绝不自动发送 |

### 特别说明

- **独立对话不等于文件隔离。** 写入模式使用主会话的工作区，可能与主 Agent 冲突。本插件没有 worktree 隔离能力。
- Agent 模式不开放 bash、命令执行、MCP、浏览器、子 Agent 或任意外部操作。`glob` / `grep` 通过宿主内置搜索实现，不是向模型开放终端。
- 不直接分叉有权 Agent；新建受限 Agent，只导入主会话用户/助手的文字快照，不继承原 Agent 的工具配置。附件、推理、系统指令和工具结果不带入。
- 恢复保留问题与回答文字、选文、初始上下文和模型选择。插件重启后新建安全 Agent，用文字历史续聊；**不恢复历史工具执行状态**。
- 模式、模型与权限在一段侧聊创建后固定。需要切换时点“新讨论”；已保存记录仍可恢复。

## 使用

1. 主会话页眉点击 **Side Chat**，或从原生右侧栏打开 Side Chat。
2. 可先在主对话正文中选中文字。选文出现在新讨论中，可编辑或清空。
3. 选择“轻聊”或“Agent”，选择当前 DSH 已配置的模型。打开面板不会请求模型；点击发送才运行。
4. Agent 默认为只读。选择工作区写入时必须勾选共享工作区风险确认。
5. 每段讨论自动保存。关闭标签会尝试停止运行；之后在相同主会话的历史列表中恢复。
6. 将需要的回答加入结论编辑区，确认后点“追加到主会话草稿”，由你检查草稿并手动发送；原草稿会保留。输入框忙碌时可以复制结论。

## 开发与安装

目标运行时为 **DSH 0.2.2-rc.1 / Node 24+**，SDK peer dependencies 精确锁定该预发布版本。不对其他版本宣称已验证；不要绕过 DSH 兼容性检查。

```sh
git clone https://github.com/SiyuQian/dsh-side-chat-plus.git
cd dsh-side-chat-plus
npm ci --ignore-scripts --legacy-peer-deps
npm run check
npm pack
```

`--legacy-peer-deps` 仅用于独立源码项目的测试依赖安装，避免拉取第二套宿主 SDK；安装到 DSH 时仍须执行插件的运行时兼容检查。

在 DSH 的插件管理中安装本地打包文件，或使用官方 CLI（安装会修改当前 profile，先确认目标 profile）：

```sh
dsh plugin --profile desktop add /absolute/path/dsh-side-chat-plus-0.1.0.tgz
```

这里的命令仅供用户主动安装。开发交付不会自动安装、修改 profile、刷新你的主会话或启动替代 Web 服务。

## 存储与隐私

讨论自动保存在 **当前 profile 的 `data/side-chat-plus/` 目录**，包括讨论文字和显式继承的主对话快照。这是本地明文，不是加密保险箱；文件创建权限为 0600，数据目录创建权限为 0700。删除按钮删除对应记录。

请求模型时，选文、已选择继承的上下文、以及讨论历史会发送给你在 DSH 中选择的提供商。Agent 可以通过开放的只读工具读取宿主允许的文件；“只读”不是“不可读取敏感文件”，请不要在含敏感信息的工作区启用未经信任的模型。

HTTP 面仅允许同源、JSON、loopback 请求，拒绝跨端口 Origin 与非本地连接。**不支持手机、反向代理、远程/多用户共享访问**；这个信任边界不是远程认证。它延续本地单用户宿主的信任模型，不防御同进程恶意插件或获得同源执行权的攻击者。

## 限制

- 默认文本渲染，保留代码/段落换行，不执行 HTML；目前不提供 Markdown 富文本、附件或图片。
- 主对话上下文是创建时快照，不会随着主对话继续推进而自动更新。
- 最大保存 100 段讨论、每段 64 次问答。主上下文、历史和输出有字符预算，超限显式报错，不悄悄截取主上下文。
- 轻聊按文本流更新；Agent 模式按已提交的助手步骤更新，不显示尚未提交的 token 流。
- 生成最长约 3 分钟；停止/超时会保留当前已收到的文字。崩溃后“运行中”记录恢复为已中断，不自动重跑。
- 若宿主配置额外可写根目录，工作区写入模式拒绝启动；只读模式仍可使用。文件访问仍遵循 DSH 的 sandbox 语义，其中可能允许部分平台临时目录，不等于只限 cwd 的操作系统容器。
- 受限 Agent 仍由宿主的受信任插件体系运行，工具白名单不是对恶意同进程代码的沙箱。

实现包含服务持久化/并发测试、HTTP 信任边界测试、宿主注册清理测试、适配器的模型/安全工具边界测试和 React/jsdom 交互测试。当前本地验证为 **78 项测试通过**，详情与安装后验收清单见 [VERIFICATION.md](VERIFICATION.md)。

当前 GUI 需要认证；未自动安装到你的 profile，因此**不能把单元测试通过视为当前 GUI 中的真实模型、真实文件权限与端到端侧聊都已验证**。首次安装后应先用无敏感内容的测试工作区验收：轻聊无工具、只读写入被拒、切换主会话不串线、关闭停止、刷新恢复、结论追加不覆盖草稿。
